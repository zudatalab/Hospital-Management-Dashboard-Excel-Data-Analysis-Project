## 📌 About The Project

The **Hospital Management Dashboard** is an Excel-based data analysis project focused on understanding hospital operations and presenting important information through an interactive dashboard.

The project transforms hospital-related data into visual insights that make it easier to analyze patient flow, service status, department distribution, and demographic patterns.

## 📊 Dashboard Components

The dashboard provides an interactive view of:

* Patient admission status
* Department-wise patient distribution
* Treatment and service status
* Gender distribution
* Age-group analysis
* Disease / service patterns
* Overall hospital operational information

## 🎯 Project Objective

The primary objective of this project was to transform raw hospital-related data into an **interactive and easy-to-understand analytical dashboard**.

The dashboard allows users to explore different aspects of the data using visualizations and interactive filters.
